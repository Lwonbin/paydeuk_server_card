# 💳 paydeuk_server_card

`paydeuk_server_card`는 카드사 시스템을 모사한 서비스로, 카드 등록, 실적 조회, 결제 처리 및 혜택 정보를 제공하는 모듈입니다.  
실제 카드사와의 연동을 대신해 `paydeuk_server_module`로부터 요청받은 정보를 처리하고 응답합니다.

---

## 주요 역할

### 1. 카드 토큰 발급
사용자가 카드를 등록하면 고유한 카드 토큰을 발급합니다. 이 토큰은 이후 실적 조회, 조건 검증, 결제 처리 시 카드 식별자로 사용됩니다.

### 2. 전월 실적 조회
특정 카드의 전월 총 사용 금액을 조회합니다. 추천 로직에서 실적 조건을 만족하는지를 판단하는 기준 데이터로 활용됩니다.

### 3. 카드 정보 조회
등록된 전체 카드 목록과 함께, 각 카드의 혜택, 할인 조건, 발급사 등의 상세 정보를 제공합니다. 사용자에게 카드 추천 시 UI에 활용됩니다.

### 4. 카드 조건 조회
특정 카드의 혜택 조건을 조회합니다. 월간 할인 한도, 일일 사용 횟수 제한, 1회당 최대 할인 금액 등 다양한 조건을 포함합니다.

### 5. 카드 결제 처리
카드 결제 요청을 처리하고, 해당 내역을 저장합니다. 할인 계산은 서버 모듈에서 수행하며, 카드사 서버는 결제 요청을 수신 및 기록하는 역할을 담당합니다.
